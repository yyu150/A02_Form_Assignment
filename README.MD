# A02 — Branch & Refactor (Gradient Night Scene)

This project is a continuation of Assignment A01.  
It uses Git branching to explore two different visual themes (sunset and night) while keeping all accessibility and form-structure requirements intact.

## 🌇 Sunset Theme
- Warm gradient palette inspired by sunset colors
- Screenshot stored in `screens/sunset.png`
- Implemented in the branch: `theme/sunset`

## 🌙 Night Theme
- Uses **one linear gradient** for the night sky
- Uses **one radial gradient** for a soft glow effect
- Maintains all structure, accessibility, and form semantics from A01
- Screenshot stored in `screens/night.png`
- Implemented in the branch: `theme/night`

## 📁 Branch Workflow
- `main` — baseline A01 form
- `theme/sunset` — sunset design with screenshot
- `theme/night` — night design, gradients, screenshot

## 🧠 Design Intent
The sunset theme focuses on warmth and color transitions.  
The night theme introduces a dark, calming palette with layered gradients for depth (sky + glow).  
Both themes follow WCAG accessibility rules, proper input labeling, and consistent layout spacing.
